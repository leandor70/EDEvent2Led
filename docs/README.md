## 🔍 Come Navigare

### Per Utenti
1. Inizia da **guides/EFFECT_LIBRARY_USER_GUIDE.md**
2. Consulta **guides/EFFECT_LIBRARY_QUICK_REFERENCE.md** per riferimento rapido
3. Vedi **guides/COLOR_SCHEME_EDITOR_GUIDE.md** per personalizzare colori

### Per Sviluppatori
1. Leggi **guides/EFFECT_LIBRARY_DEVELOPER_GUIDE.md**
2. Consulta **guides/INTEGRATION_GUIDE.md**
3. Vedi **references/UNIFIED_SYSTEM_README.md** per architettura

### Per Testing
1. Usa **guides/QUICK_HARDWARE_TEST.md** per test rapidi
2. Consulta **reports/HARDWARE_TEST_REPORT.md** per test completi
