About ED:Event2Led

ED:Event2Led is a real-time RGB lighting control application for Elite Dangerous. It monitors the game's journal files and synchronizes your RGB hardware (keyboard, mouse, case lighting, etc.) with in-game events using OpenRGB.

From hyperspace jumps to docking procedures, combat alerts to fuel warnings, every Elite Dangerous event can trigger a custom lighting effect, creating an immersive ambient experience that extends beyond the screen.

System Requirements

  • › Windows 10/11 (64-bit)
  • › OpenRGB — RGB control server (open-source, available at openrgb.org)
  • › Elite Dangerous — Journal files enabled (default)
  • › Python 3.11+ — Runtime environment
  • › RGB Hardware — Keyboard, mouse, case lighting, etc. (supported by OpenRGB)

Quick Start

  1. 1. Configuration — Connect to OpenRGB, set the Elite Dangerous journal path, and choose your language.
  2. 2. Device Management — Enable the RGB devices you want to control and configure their behavior.
  3. 3. Effects Editor — Create multi-step lighting sequences: choose colors, durations, and transition types.
  4. 4. Event Mapping — Assign each effect to one or more Elite Dangerous events and set priority levels.
  5. 5. Start Monitoring — Press the Start button on this page. ED:Event2Led will process journal events in real-time.

Data & Privacy

ED:Event2Led operates locally. It reads Elite Dangerous journal files on your machine and communicates with OpenRGB over localhost. The only connection to the internet is an optional check for new versions: at startup the app asks GitHub for the latest release, sending only its name and version. You can turn it off in Settings. No other data is collected, transmitted, or stored externally. Configuration is saved in local JSON files in the config/ directory.
