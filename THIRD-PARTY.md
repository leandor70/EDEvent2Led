## OpenRGB

ED:Event2Led talks to [OpenRGB](https://openrgb.org) over its network SDK. It does
not contain OpenRGB code and no OpenRGB library is bundled: the client in
`src/utils/openrgb_client.py` is original work written from the public protocol
description. OpenRGB is a separate program under its own license (GPL-2.0).
Releases up to 1.2.0 bundled the `openrgb-python` library (GPL-3.0); it is no
longer used.
